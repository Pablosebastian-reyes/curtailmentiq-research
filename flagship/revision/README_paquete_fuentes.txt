SEGAN-D-26-03850 -- LaTeX source package (major revision)
An open curtailment dataset and a diagnostic for adaptive conformal
calibration under regime change
Reyes Cerda, P. and Cea Morales, K.

HOW TO COMPILE
--------------
Place every file of this archive in a single flat directory and run:

    pdflatex SEGAN_paper_FINAL.tex
    pdflatex SEGAN_paper_FINAL.tex
    pdflatex SEGAN_paper_FINAL.tex

Three passes are required to resolve cross-references. The result is a
35-page PDF with no unresolved references and no warnings about missing
citations.

BIBLIOGRAPHY: NO BibTeX RUN IS NEEDED
-------------------------------------
There is no .bib and no .bbl file in this archive, and none is needed.
The 43 references are typeset from a `thebibliography' environment
written inline in SEGAN_paper_FINAL.tex (see the end of the file). No
BibTeX or Biber invocation is required at any point, so the build cannot
depend on the availability of a .bst style on the production server.

OTHER PACKAGES
--------------
Beyond elsarticle.cls the source uses only packages shipped with a
standard TeX Live or MiKTeX installation: amsmath, amssymb, amsfonts,
graphicx, booktabs, url, hyperref, siunitx, multirow, longtable,
algorithm and algpseudocode. None is included here.

PROVENANCE
----------
Every table body and every figure in this archive is generated by a
script in the authors' public repository; no numeric value in the
manuscript is typed by hand. Table bodies come from
flagship/revision/fase9_tablas_tex.py and the figures from
flagship/revision/fase9_figuras_revision.py.
